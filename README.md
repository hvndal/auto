# Auto-Esthetica Québec — Maquette Interactive

Site web vitrine et maquette de démonstration interactive pour **Auto-Esthetica Québec** (esthétique automobile haut de gamme, protection PPF CARPRO Immortal, nano-céramique, polissage et unité mobile autonome à domicile).

## Structure du projet

- `index.html` : Application web complète (HTML5, CSS3, JavaScript moderne natif)
- `assets/img/` : Médias locaux optimisés (photos réelles d’interventions, logo transparent haute résolution, favicon)
- `rapatrier-images.sh` : Script de rapatriement des visuels

## Caractéristiques & Fonctionnalités

- **Bandeau Démo Supérieur** : Avis de maquette interactive et invitation aux révisions
- **Slider Avant / Après automatique** : Comparaison interactive de polissage, céramique, PPF et intérieur
- **Grille tarifaire dynamique** : 5 onglets avec tarifs et forfaits détaillés en dollars canadiens
- **Section Unité Mobile** : Présentation de la remorque autonome pour services à domicile
- **Générateur de soumission** : Formulaire multi-étapes avec compression et prévisualisation de photos
- **100 % Autonome** : Fonctionne hors-ligne sans dépendances externes lourdes
